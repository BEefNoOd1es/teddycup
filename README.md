# 泰迪杯数据挖掘挑战赛项目代码说明

## 1. 项目简介

这是我们为泰迪杯数据挖掘挑战赛编写的量化选股项目。由于比赛期间团队进行了分工重构，代码从一开始只能跑基础回测的**原始版本**，演变成了现在包含网页爬虫、大语言模型文本分析、事件研究法和知识图谱的**整合版本**。

为了方便测试，我们把跑通整个流程所需的脱敏数据（行情CSV、跑过大模型打好标签的JSON）单独放到了 `程序跑通/` 文件夹（也就是示例文件夹），大家可以直接在这个文件夹里测试，不需要再去配各种大模型的API或者爬虫环境。

---

## 2. 目录结构说明

### 原始版本（基础版）
位于 `程序原始版本/` 文件夹。这是早期的雏形，只能基于本地固定的数据计算收益率和简单的净值，没有加入自然语言处理相关的模块。

### 现在的完整版（整合版）
主要位于 `程序/` 和 `程序跑通/` 文件夹。为了满足赛题要求我们加入了以下模块：

*   **前置处理**：
    *   `cls.py`: 用 Playwright 爬取新闻和事件。
    *   `llm_analyze.py`: 用 DeepSeek/OpenAI 接口给文本打标签（分辨利好/利空）。
    *   `select_stocks_from_events.py`: 提取事件和对应股票。
    *   `main_pipeline.py`: 把上面几步串联起来的数据处理主程序。
*   **分析建模**：
    *   `Task2_KnowledgeGraph.py`: 用 NetworkX 画知识图谱。
    *   `EventStudy_CAR.py`: 给事件算异常收益率（CAR）。
*   **回测框架（在老版本上改的）**：
    *   `main.py`: 回测流程的主入口，重构后支持接收多因子数据。
    *   `RiskFilter.py` & `PortfolioManager.py`: 风控和仓位管理，加入了基于情绪标签的熔断判断和图谱权重。
    *   `BacktestEngine.py` & `MetricsPlotter.py`: 负责跑交易回测和画资金曲线图。

---

## 3. 如何运行示例代码 (快速上手指南)

我们推荐直接跑 `程序跑通/` 文件夹下的代码。因为这里面已经包含了必要的行情文件（`日线数据.csv`）和处理好的事件数据（`test2.json`）。你可以跳过爬虫和大模型调用，直接看项目的核心流程是怎么跑通的。

### 步骤 1：安装依赖环境

如果没有相关依赖，需要先安装（建议 Python 3.9 或 3.10）：

```bash
pip install pandas numpy matplotlib networkx
```
*(注意：如果你只想跑示例目录，不需要装 playwright 和 openai 等爬虫/大模型库)*

### 步骤 2：进入示例目录

```bash
cd 程序跑通
```

### 步骤 3：数据提取与整合 (运行 main_pipeline)

主要功能是把 JSON 格式的新闻事件读取出来，跟本地的股票代码和概念板块做匹配，并把成功的记录存进本地 SQLite 数据库中。

```bash
python main_pipeline.py
```
运行完后，你会在目录下看到生成的 `selected_events2.db` 和相关的临时 json 文件。

### 步骤 4：执行量化回测与画图 (运行 main)

这一步会读取刚才生成的数据库，以及目录下的 `日线数据.csv`，先过一遍风控（剔除ST、波动过大的股票），然后执行买卖逻辑，最后生成净值图和评价指标。

```bash
python main.py
```
运行成功后，终端会打印出相关的收益指标数据，并在 `result/` 目录下生成 `account_value.csv` 等多维度结果数据。
